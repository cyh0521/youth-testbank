01

快速開始

第一次使用，可先從「電腦選題」建立一份小份量的練習卷。

登入→點選首頁冊別圖卡→選擇出題方式→確認範圍與配分→預覽、儲存與輸出
01電腦選題給條件，讓系統幫你挑題↗02手動選題一題一題，挑出理想內容↗03編碼選題已有題號，直接加入試卷↗04題本列印整冊或章節，整理成練習題本↗05試卷管理找回試卷，編輯或再次輸出↗
開始前請確認已有帳號及穩定的網路連線。畫面中的冊別與可選題數會依題庫內容、帳號設定而不同。
02

登入與首頁

  1. 開啟網站，在登入欄位填入電子信箱與密碼。
  2. 點選登入，等待進入首頁。若無法登入，先檢查信箱、密碼與網路；帳號問題請聯繫服務人員。
  3. 在首頁的選擇出題科目區，點選你要使用的冊別圖卡。
  4. 在彈出的視窗選擇電腦選題、手動選題、編碼選題或題本列印。系統會將所選冊別帶入下一頁。

把常用冊別放前面

點選首頁圖卡上的勾選圖示，可設為常用或取消常用；出題方式視窗也有設為常用科目並置頂顯示選項。儲存成功後，常用冊別會排在前方。

常用置頂與顯示範圍不同。首頁的常用功能調整排列順序；「設定 → 常用科目」則決定哪些科目與冊別要出現在日常選題畫面。

個人資訊與登出

點選右上角頭像，可開啟個人資訊或登出。共用電腦使用完畢後，請主動登出。

03

選擇出題範圍

電腦、手動、編碼選題及題本列印，都從確認科目、冊別與章節開始。

  1. 在左側選擇科目與冊別。從首頁進入時，請確認帶入的冊別是否正確。
  2. 參考左側總題數與題型分布，了解該冊收錄內容。
  3. 在右側勾選要使用的章節。若有節或小節，可展開目錄，再挑選更細的範圍。
  4. 確認可選題數後，點選右上角的下一步。
找不到冊別時，請先檢查「設定 → 常用科目」是否已勾選並儲存，然後重新整理選題頁。
04

電腦選題

適合先決定出題範圍、題型與題數，讓系統協助挑選。

  1. 依出題範圍的步驟選好冊別與章節。
  2. 在題型與題數輸入各題型需要的數量；不需要的題型保留為 0。
  3. 在試卷難易度調整比例。實際結果仍會依題庫中可用題目調整。
  4. 設定每題配分，或使用自動配分。核對總分；需要時取消整數配分，改以 0.5 分為調整單位。
  5. 點選下一步：自動選題，閱讀系統挑出的題目。可切換清單／完整顯示，並依畫面提供的換題、刪除或重新選題功能調整。
  6. 確認後進入試卷設定，再前往預覽。
填空題請留意格數。畫面以「格」標示時，設定的是填空格數與每格分數，不一定等於題目篇數。
特色功能

章節題目比重：讓重點章節多出一點

同一份試卷涵蓋多個章節時，不一定希望每章出一樣多的題目。例如剛教完的重點章節可以設為「較多」，複習章節設為「較少」，其餘維持「一般」。

  1. 在「出題範圍」先勾選本次要考的章、節或小節，再進入「題型與配分」。
  2. 點選「題型與題數」右上角的章節題目比重。
  3. 移動各列滑桿，分別選擇較少、一般、較多。若有節或小節，列表依目前選取範圍的最末層呈現。
  4. 點選完成返回，確認題型、題數與難易度，再執行自動選題。
  5. 在選題結果與預覽的命題範圍中，檢查實際選入的題數是否符合教學需求。
「較多」不是固定題數或百分比。系統仍須同時滿足題型、可用題目與難易度條件。題數足夠且條件可滿足時，會先兼顧所選各節；若題目不足或條件衝突，請依提示調整。調整比重後，要重新選題才會影響已有的選題結果。

05

手動選題

適合逐題閱讀、依自己的教學需求挑選。

  1. 選好冊別與章節後，進入選擇題目。
  2. 在左側題目庫閱讀題目；可用條件選擇與搜尋欄縮小清單。
  3. 點選題目旁的加入，題目會出現在右側已選題目。
  4. 使用清單／完整切換顯示方式。檢查已選題目，移除不需要的內容；有排序操作時，可拖曳調整。
  5. 點選下一步：題型與配分，設定分數，再完成試卷設定及預覽。
06

編碼選題

已記下題目編號時，可直接輸入編號挑題。

  1. 先選擇含有該題的冊別與章節範圍，進入編碼選題。
  2. 單題加入：輸入五位數編號（例如 00007），確認查得的題目後點選加入。
  3. 批次加入：在批次欄每行輸入一個編號，或以空白、逗號、頓號分隔，再點選批次加入。
  4. 查看新增、重複、範圍內未找到與格式無效的提示，確認右側已選題目。
  5. 繼續設定配分、試卷表頭與預覽。
編號是題目的識別碼，不是試卷上的第幾題。建議保留前面的 0，按畫面顯示的五位數編號輸入。
07

設定、預覽與儲存試卷

先核對試卷設定

  1. 在試卷檢視核對題型、題數、配分與總分。
  2. 需要調整題型順序時，拖曳可排序的列或依畫面提供的排序功能操作。
  3. 在試卷表頭填入學校、學年度、科目、考試名稱等需要顯示的文字，設定班級、姓名、座號的預留格數。
  4. 前往預覽試卷。

預覽時看哪些地方？

  • 確認題目、選項、分數與題型順序。
  • 依需要勾選解答、解析、頁數、難易度；「試卷表頭」與「字體與行距」可再調整。
  • 左側命題範圍可展開、收合；點選章節可協助查看對應題目。畫面上的範圍標示不會當成試卷內容輸出。
  • 核對解答顯示後，再決定要列印或下載哪一種卷型。
特色功能

同一份試卷，切換解答、解析、頁數與難易度

預覽頁提供四個獨立的顯示選項，可依檢查目的自由組合，不必另外建立一份試卷。

顯示選項可以怎麼用？
解答顯示題目答案，方便核對；取消勾選可查看不含答案的題目畫面。
解析查看題庫已收錄的解題說明，協助備課與講解；未收錄解析的題目不會另行產生內容。
頁數顯示題目記錄的課本頁數／來源資訊，方便回查教材，並非試卷的分頁頁碼。
難易度顯示各題的難易標記，檢查整份試卷的配置。
  1. 進入預覽試卷，找到試卷內容上方的四個核取方塊。
  2. 勾選需要的解答、解析、頁數、難易度，立即查看試卷呈現；再次取消勾選即可隱藏。
  3. 搭配左側命題範圍標示，檢查題目出處、答案與章節配置。
這些操作切換的是顯示內容，不會刪除題目的答案或解析。下載 Word 時，仍請在下載視窗確認所選卷型是否附答案、解析。
特色功能

依命題章節標示題目：快速檢查這份卷考了什麼

試卷長、跨越多個章節時，不必逐題尋找出處。預覽左側的命題範圍會列出章節與本卷題數；點一下章節，就能在試卷上辨識該範圍的題目。

  1. 進入預覽試卷，找到左側命題範圍。若已收合，先點選展開圖示。
  2. 需要時展開章、節、小節，查看各範圍收錄在本卷中的題數。
  3. 點選章節名稱，對應題目會出現淡黃色底色。這是標示題目，不是把其他題目移除。
  4. 點選另一個章節可切換標示；再次點選同一章節可取消標示。
  5. 對照各章題數與標示結果，確認是否偏重某個範圍，再決定是否返回調整題目。
標示只供預覽檢查。不會改變題目、配分或題序，也不會帶入列印與 Word 下載。切換解答、解析或字型時，可保留目前的章節標示。

儲存到試卷管理

新建試卷完成後，點選畫面上的儲存，填寫試卷名稱與選填說明，再確認儲存。成功後可至頂欄試卷管理找回。

下載與儲存是兩件事。下載 Word 是把檔案留在裝置；儲存試卷才會讓它出現在帳號的試卷管理。離開未儲存的出題頁前，請先完成儲存。
08

列印與 Word 下載

下載 Word 檔

  1. 在預覽頁或試卷管理點選下載。
  2. 選擇A3、A4 或 B4（JIS）及單欄／雙欄。
  3. 勾選要下載的卷型。可複選，系統會依序下載檔案。
  4. 需要不同題序時可勾選AB卷；輸出後請核對兩卷的題序與答案。
  5. 點選下載，完成後到裝置的下載資料夾開啟 .docx 檔案。
卷型用途
題目卷學生作答用的題目。
題目卷附答案核對答案或教師參考。
題目卷附答案及解析講解、複習與教師參考。
作答卷另行填寫答案的作答格式。
作答卷附答案作答卷的答案參考版本。
特色功能

AB卷與多卷型：同一次準備不同使用版本

下載時可同時勾選「題目卷」、「題目卷附答案」、「作答卷」等類型，依序取得學生與教師使用的版本，不必重新出題。

勾選AB卷後，A 卷保留原題序，B 卷在同題型內調整題目順序；題本則同時保留章節分組。兩卷使用同一組題目，不是另抽一組新題，也不是打亂選項。

如果每個可調整的題型／章節都只有一題，無法產生不同題序。下載後請分別核對 A、B 卷與對應答案，並依印出的檔名發放。

直接列印

點選列印，依網站的列印設定選擇紙張與欄數，再於瀏覽器列印視窗確認印表機、紙張、方向與縮放。第一次使用建議先檢查列印預覽，必要時先輸出一頁確認。

瀏覽器、印表機與 Word 的排版結果可能略有差異。正式印製前，請再次確認分頁、選項與答案；若瀏覽器詢問是否允許多個檔案下載，請依本次選取的卷型決定是否允許。
09

題本列印

依選定範圍整理題目，適合整冊練習或章節複習，不需逐題設定出題數。

  1. 從首頁冊別圖卡選擇題本列印，或由頂欄的出題與列印進入。
  2. 選擇科目、冊別與要收錄的章節；要整理整冊時，選取所有可用章節。
  3. 點選預覽題本，核對章節與題目內容。
  4. 依需要調整解答、解析、頁數、難易度及字體行距，再列印或下載。

10

試卷管理

點選頂欄試卷管理，查找帳號可存取的已儲存試卷。

  1. 在搜尋欄輸入試卷名稱，或使用冊別下拉選單縮小範圍。
  2. 點選欄位標題可排序；再次點選可切換升冪／降冪。
  3. 使用列表中的預覽、列印、下載取得試卷。
  4. 需要修改時點選編輯，完成調整後點選儲存。

編輯時可以調整什麼？

依畫面提供的操作，可修改名稱與說明、檢查命題範圍、調整試卷表頭、題型順序及配分，也可換題、刪除題目或調整題目順序。清單／完整切換只改變檢視方式。

特色功能

題目不合適？選題中、儲存後都能調整

不必因為一兩題不合適就重做整份試卷，可先針對個別題目更換，再核對內容與配分。

選題過程中

  1. 電腦選題：在「自動選題」結果找到要調整的題目，點選該題旁的換題；若想整批重新挑選，使用重新選題。
  2. 手動選題：先從右側已選題目移除不需要的題目，再從左側題目庫加入另一題。
  3. 編碼選題：移除不需要的已選題目，輸入另一個範圍內的題號並加入。
  4. 完成後回到配分與試卷設定，確認題數、總分與題型順序。

試卷儲存之後

  1. 到試卷管理找到試卷，點選編輯。
  2. 找到要替換的題目，使用該題的換題操作，再閱讀新題目確認是否合適。
  3. 核對題數、配分與總分，點選儲存，再預覽或重新輸出。
系統換題仍受可用題目、題型、填空格數及命題範圍等條件限制；沒有合適替換題目時會顯示提示。換題後務必重新核對答案與配分，已下載的舊檔案不會自動更新。
查看編輯試卷畫面
刪除前先確認。刪除試卷後，不能從試卷列表取回；重要試卷可先下載留存，再決定是否刪除。
11

個人設定

點選頂欄設定，或從右上角頭像的個人資訊進入。設定頁的頁面名稱為「進階設定」。

個人資料、頭像與密碼

  • 編輯個人資料：修改可編輯的姓名、暱稱或學校等欄位，完成後儲存。
  • 編輯頭像：選擇預設頭像，或上傳自己的 JPG、PNG、WebP 圖片，再儲存。
  • 更新密碼：輸入目前密碼、新密碼與確認新密碼。新密碼至少 6 個字元；儲存成功後，往後登入請用新密碼。

常用科目：決定要顯示哪些冊別

  1. 切換至常用科目。
  2. 勾選要顯示的科目與冊別。
  3. 捲到操作按鈕並點選儲存變更。
  4. 回到首頁或重新整理原本的選題頁，確認顯示結果。

試卷版面設定

在試卷版面設定調整新試卷預設的表頭、字型、字級、行距與邊距。完成各區調整後，點選該區的儲存變更；若畫面提供套用範圍，請先確認要影響哪些試卷。

12

常見問題

為什麼首頁、下拉選單少了某冊？

先至「設定 → 常用科目」確認科目與冊別均已勾選，再儲存並重新整理。若冊別仍不存在，請聯繫服務人員確認題庫內容。

為什麼有冊別或章節，卻無法選題？

該範圍可能尚無可用題目，或題目未符合目前條件。先查看可選題數，嘗試擴大範圍、減少題數或調整題型；仍無法使用時請聯繫服務人員。

編碼查不到題目怎麼辦？

核對五位數編號，以及目前選擇的科目、冊別和章節。編碼選題只會在選定範圍內找題，不會自動切換冊別。

下載完了，為什麼試卷管理沒有出現？

下載只產生檔案。請回到出題流程使用「儲存」，填寫名稱並確認成功，試卷才會出現在試卷管理。

同時選了多種卷型，卻只下載一份？

檢查瀏覽器是否阻擋多個檔案下載；也可以每次只選一種卷型，分次下載。

列印或 Word 版面與預覽不同？

確認紙張大小、方向、單雙欄與縮放設定。不同字型、瀏覽器及 Word 版本可能影響換行與分頁，正式印製前應先檢查輸出結果。

登入失效或頁面一直載入怎麼辦？

先確認網路，重新整理或重新登入。若出題內容尚未儲存，請留意重新整理可能使本次未儲存的內容遺失。
