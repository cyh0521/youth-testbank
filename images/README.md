# 網站圖片

此資料夾存放透過 GitHub Pages 發布的題目圖片與網站 Logo（`youth.png`）。

1. 在「題目維護 → 編輯」將文字游標放到要插入圖片的位置，按「選擇圖片」，選取 PNG 或 JPG。
2. 點選圖片可修改顯示寬度、圖片說明，或移除圖片。
3. 儲存題目時，系統會下載「題目編碼-圖片.zip」。解壓後，把其中 `images` 資料夾內的圖片放進儲存庫的此資料夾，保留原檔名，再提交／發布網站。
4. GitHub Pages 完成部署後，各裝置便可正常顯示圖片。上傳前，新圖片只在目前瀏覽器頁面顯示本地預覽；重新整理或其他裝置尚無法讀取。

已有圖片可按「插入已上傳圖片」，輸入例如 `images/example.png` 的相對路徑。檔名與子資料夾使用英數字、底線或連字號；不接受外部網址。

舊題庫中以 `question-images/` 開頭的圖片路徑會自動讀取 `images/` 的同名檔案；再次編輯儲存時會改存新路徑。

圖片會依比例縮小到最長邊 1600 px，PNG 保留透明背景，JPG 使用 90% 品質。題庫只保存圖片相對路徑、顯示寬度與說明，不保存圖片內容，也不使用 Firebase Storage。

移除題目中的圖片不會自動刪除 GitHub 檔案，避免影響仍引用同一圖片的其他題目或已儲存試卷。
