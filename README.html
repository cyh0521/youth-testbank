01

專案定位

幼獅文化線上命題系統，供教師與管理員建立題庫、組卷、保存試卷及紙本輸出。採 HTML、CSS 與原生 JavaScript，搭配 Firebase 驗證／資料儲存及 GitHub Pages 靜態題庫。

教師管理自己的試卷；管理員另負責課本目錄、題目匯入與維護及帳號管理。班級、姓名、座號是試卷表頭內容，目前不提供學生帳號、線上作答或成績管理。

筆記的閱讀方式

先看目前功能與編寫決策，再沿時間查看開發紀錄。歷史紀錄保留當時做法，已被改版取代的導覽、表頭或輸出功能，請以目前說明為準。

02

重點特色

舊題本反譯成入題檔

管理員可批次解析舊版 DOCX 題本，確認科目、冊別、章節及題目欄位，分別下載選擇題／其他題型的入題表格，保留段落與內嵌圖片。

三種選題方式

電腦依條件組卷、手動逐題挑選、編碼批次加入；共用範圍、配分、表頭與預覽流程。

有彈性的配分與選題

支援六類題型、自動配分、整數／0.5 分調整、難易度比例及章節比重。填空按格計分，保留完整題目。

試卷與題本輸出

列印或下載真正的 DOCX；可產生附答案／解析、作答卷與 A／B 卷。題本依章節整理全部題目。

預覽、編輯與再利用

章節目錄可標示對應試題；支援題目與題型排序、換題、刪除，以及試卷搜尋、冊別篩選與再次輸出。

帳號保存個人習慣

常用冊別置頂；字型、行距、邊距與新試卷表頭依帳號保存。每張試卷另存自己的表頭與外觀。

綠色插畫介面

頂部導覽、冊別卡片與登入插畫統一視覺；插畫位於 images/illustrations/，支援窄螢幕與鍵盤操作。

目前使用方式與功能邊界

  • 首頁按冊別顯示插畫卡片；卡片勾選及出題方式視窗的常用勾選同步，儲存成功後立即置頂。常用冊別排序與設定頁的科目顯示偏好是兩份設定。
  • 表頭第一列為自由文字，第二列固定班級、姓名、座號，格數可設 0–12；舊表頭在尚未填寫新文字時合併顯示，清空新文字後不再自動復原。
  • Word 下載可複選題目卷、附答案、附答案與解析、作答卷、作答卷附答案。B 卷只改同題型題序，各卷答案跟著題目移動；無可重排題組時明確提示。
  • 題本按最末層章節分組、按編號排序，各節各題型重新編號。解答、解析、出處及難易度勾選控制預覽與輸出，題本不使用一般試卷的卷型選單。
03

編寫重點

  • 共用流程：js/exam-scope.js 管理出題範圍，js/compose-selection.js 處理選題，js/exam-preview.js 與 js/docx-export.js 負責預覽及輸出，減少各頁重複邏輯。
  • 讀題與維護分開：一般出題讀取 data/testbank/；管理頁使用 Firestore。靜態載入失敗明確中止，不自動改讀備用題庫；管理員可切換全站來源。
  • 保留舊資料：試卷保存題目順序、表頭、外觀與計分單位。舊表頭可合併為自由文字；未標記按格計分的舊填空試卷維持原方式。
  • 輸出專用排版：Word 使用 OOXML、定位點與懸掛縮排處理題號續行，指定東亞字型並關閉貼齊格線；瀏覽器預覽與 Word 分頁仍可能不同。
  • 權限由後端驗證：頁面經登入守衛啟用，資料存取受 Firestore 規則限制；導覽的角色快取只控制外觀。主要管理員、管理員與教師依角色開放操作。
  • 介面與內容安全：動態文字做 HTML 跳脫，對話框提供關閉及鍵盤操作；流程動畫尊重減少動態效果設定。插畫、題目圖片與字型隨專案管理。

選題邏輯：把限制寫清楚

章節比重以較多／一般／較少＝3／2／1 分配。題數足夠涵蓋各節時優先每節至少一題；題數少於節數時允許部分章節出題。若指定題型不足或填空無法湊足格數，要求調整條件，不悄悄少出題。重新選題與個別換題沿用相同限制。

難易目標為偏難 70%／30%、適中各 50%、偏易 30%／70%，依實際題庫調整。填空以完整題目組合湊足格數；新試卷以 scoreUnits.T4="blank" 標記，保留舊試卷按題計分的相容性。題型順序與章節比重分別保存於 typeOrder、sectionWeights。

資料來源：更新有版本，故障可切換

manifest 提供每冊題目檔與 ID 索引，課本目錄與題目共同匯出；目錄檔名含內容雜湊，保留原 ID、空冊與完整層級。靜態讀題共用載入快取，避免每次操作重複讀取；維護頁直接讀 Firestore，避免剛編輯的內容被尚未發布的 JSON 蓋掉。

全站來源存於 settings/textbankMode；缺少設定或讀取失敗時使用程式預設值。靜態讀題失敗不自動回退 Firestore，避免來源不明與額外讀取。圖片只保存相對路徑、寬度及說明，檔案另行發布。

試卷快照：預設與成品分開

使用者的 examPreferences 保存新試卷預設；每張試卷另保存表頭與外觀。修改帳號預設前，為尚無快照的舊試卷保存當時值；草稿修改保留在草稿。這個分界避免改一次字型或表頭就改動其他已完成試卷。

反譯模組與圖片匯入

js/reverse-import.js 以本地 JSZip 讀取 DOCX 的 XML 與關係檔，解析題目並使用 assets/reverse-import/choice.docx、other.docx 組裝入題檔。js/reverse-import-page.js 負責管理員驗證、檔案狀態、目錄比對、欄位編輯與下載。

反譯檔案在瀏覽器處理，不直接寫題庫。題目匯入用 Mammoth 提取 PNG／JPG，以內容雜湊建立圖片相對路徑並保存圖片標記；題目與圖片檔分開發布，避免把圖片內容塞進 Firestore。

05

操作與資料更新

教師組卷

  1. 登入後選首頁冊別卡片，再選電腦、手動或編碼選題。
  2. 設定範圍、題目與配分，核對表頭及預覽後儲存。
  3. 從試卷管理查找、編輯、列印或下載；Word 可選 A3／A4／JIS B4、單雙欄與卷型。直接列印依瀏覽器提醒設定。

題本入口可整理指定章節的全部題目，輸出沿用解答、解析、出處與難易度勾選；題本不保存為試卷，也不提供 A／B 卷。

管理員更新題庫

  1. 在課本管理建立目錄，匯入 Word 題目，再到題目維護檢查與編輯。
  2. 重新匯出完整靜態題庫，放入 data/testbank/，執行資料驗證，再隨網站發布；Firestore 原資料保留。
  3. 新題目圖片由編輯器下載 ZIP，放入 images/ 再發布。詳細步驟見 題目圖片說明。

課本目錄、每冊題目及 manifest 必須屬於同一版本；更新名稱、章節或題目後都要重新匯出。圖片不使用 Firebase Storage，Word 匯入已支援 PNG／JPG，仍需另行下載圖片 ZIP 並發布。

電腦選題的五步流程

出題範圍 → 題型與配分 → 自動選題 → 試卷設定 → 預覽試卷。選章節可使用 Shift 範圍勾選，空冊／空章節停用。自動選題可切換清單／完整、拖曳同題型題目與換題；試卷設定核對摘要與總分，調整題型順序。儲存時再填名稱與說明，完成後保留在預覽頁。

題目維護與匯入

Word 入題檔依表格欄位解析難易度、章節、題型、出處、答案、題幹、選項與解析；匯入分為選科目、上傳、預覽、確認四步，每檔上限 20 MB。題目維護支援章節、題型與關鍵字篩選，以及表格／卡片檢視。

單一換行與獨立段落分開保存：Shift+Enter 為段內換行，Enter 為換段。新插入的 PNG／JPG 先在本機頁面預覽，儲存題目時下載圖片 ZIP；尚未發布的圖片不會立即出現在其他裝置。

舊版題本反譯流程

  1. 管理員從「題目匯入 → 舊版題本反譯成入題檔」開啟工具，上傳一個或多個 DOCX；不是一般試卷下載功能。
  2. 解析後確認科目與冊別。若章節標題無法唯一辨識冊別，需手動選擇；逐題檢查題型、題目、答案、選項及章節序號。
  3. 可直接修改欄位；Enter 換段、Shift+Enter 段內換行。圖片以「⟦圖編號⟧」標記，可在欄位間移動，下載時還原為內嵌圖片。
  4. 修正驗證錯誤後，分別下載選擇題或其他題型 DOCX，再返回題目匯入。匯入預覽中可下載「入題圖片 ZIP」，解壓至網站根目錄並發布 images 資料夾。

反譯會檢查題型、非空題目與答案、選項、答案指向的選項、圖片編號與冊別章節層級；驗證錯誤會停用下載。工具使用已發布靜態目錄，課本資料更新後須先重新匯出發布。

輸出全文新細明體；填空連續底線使用 Times New Roman，僅選擇題簡答欄英數字使用全形。圖片保留原尺寸，以段內換行附圖；選擇題題幹圖片移至結尾，選項／解析圖片仍保留所在欄位。

Word 排版為什麼改過多次

早期以 HTML 冒充 Word，後改為真正 DOCX。接著處理儲存格交界造成題號後空白、東亞文字貼齊格線拉大行距，以及段落限制顯示黑色編輯方塊。改用懸掛縮排、明確字型、snapToGrid=false 與可辨識的行距規則，分開處理文件結構與使用者看到的版面。

曾以 16 px、1.85 行距案例確認 444 twips 與 lineRule=exact，並檢查表頭粗體、解答分隔線及底框距離。這些是歷史測試案例；現行預設題目行距 1.3、表頭 1.6，不應混為一談。

預覽與介面的修正經驗

答案開關原會改變括號寬度，改為固定作答區；解析以標籤與內文分區，讓換行對齊正文。跨頁過渡曾造成側欄短暫消失，改為同步繪製導覽；Word、預覽與直接列印共用內容，但採各自適合的排版。
