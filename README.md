# 幼獅題庫系統 v2（出題列印版）

## static-testbank 分支：靜態題庫試行

此分支正在試行以 GitHub Pages 的 JSON 檔供應題目。正式題庫已匯出至 `data/testbank`，`js/textbank-mode.js` 目前設為 `static`，僅影響此分支的本機預覽；線上網站仍須由 GitHub Desktop 發布後才會更新。

1. 管理員在「題目匯入」第一步按「匯出靜態題庫」。此操作會從 Firestore 伺服器讀取全部題目、科目、冊別與章節目錄並下載 ZIP；請在讀取配額足夠時操作。匯出內容只包含出題所需欄位，不包含匯入檔名、建立者或時間戳記。
2. 將 ZIP 內的 `data/testbank` 解壓至專案根目錄，保留 `manifest.json` 與 `books` 子目錄。原 Firestore 題目不要刪除。
3. 在專案根目錄執行 `node scripts/verify-textbank.mjs`，核對每冊題數、題目 ID 與索引。再執行 `node --test tests/static-textbank.test.mjs`。
4. 在測試分支以 `static` 模式測試各冊出題、題目搜尋、舊試卷預覽、圖片及匯出。畫面右下角會顯示題庫來源；靜態檔載入失敗會顯示錯誤並中止該次讀題，不會悄悄改讀 Firestore。可在瀏覽器開發者工具的「網路」分頁確認題目請求指向 `data/testbank/books/*.json`，且出題期間沒有 `questions` 的 Firestore 讀取請求。
5. 題目新增、編輯與刪除仍發生在 Firestore；題目或課本目錄每次變更後需要重新匯出、驗證，並透過 GitHub Desktop 發布 JSON。發布前，普通出題頁面仍會讀取上一版靜態題庫；管理員的題目維護、課本管理及匯入頁面直接讀 Firestore，以便檢查尚未發布的變更。靜態模式的出題頁則從同一份 manifest 引用的 `catalog-*.json` 讀取科目、冊別與章節，目錄保留原 ID 與空冊。

管理員可到「進階設定 → 題庫來源」將全站讀題來源切換為 Firestore 備用模式，所有使用者的新讀題請求會採用新來源；已載入題目的頁面需重新整理。右下角狀態提示預設關閉，僅主要管理員可在同頁開啟，選項儲存在自己的帳號。此設定儲存在 Firestore 的 `settings/textbankMode`，每個登入頁面以一筆設定監聽取得，題目匯入與編輯仍寫入 Firestore。若設定文件不存在或讀取失敗，網站使用 `js/textbank-mode.js` 的預設值。Firestore 的原題目資料在整個試行期保留。切換版本前先確認 GitHub Pages 發布來源及快取；舊頁面可能短暫留在瀏覽器快取中。

若 GitHub Pages 的發布來源仍是 `main`，在 GitHub Desktop 先於 `static-testbank` 提交並推送變更；確認本機測試後再切到 `main`，將 `static-testbank` 合併進 `main` 並推送。僅推送 `static-testbank` 不會更新目前由 `main` 發布的網站。上線後先在正式網址確認出題頁顯示「題目讀取成功」，再測試一份舊試卷。遇到靜態題庫故障時，管理員可在「進階設定 → 題庫來源」即時切換全站至 Firestore，待靜態題庫修復後再切回。

## 系統定位

本系統是供管理員與教師使用的線上題庫與試卷製作工具，主要流程為題庫建置、選題組卷、試卷存檔、預覽、列印與 Word 匯出。

試卷表頭可保留「班級」欄位作為考卷內容；系統不提供班級分類、學生名單、線上作答或成績管理。

Bug 修正與驗證紀錄請見 [`fix_report.md`](fix_report.md)。

## 2026-10-06 題本列印與 Word 匯出更新

- 「題本列印」已提供「出題範圍 → 預覽題本」兩步流程，從側邊欄進入即可選擇科目、冊次與章節，輸出所選範圍內的全部題目。首頁同名按鈕目前仍停用並標示「即將推出」，尚未與側邊欄功能同步。
- 題本依最下層章節分組，按章節編號的數值順序排列；每組先分行以粗體顯示完整層級名稱，名稱取自課本管理，支援單元／章／節等冊別自訂層級。最後一行下方加細黑分隔線，再依題型列出題目。
- 每節內各題型的題號從 1 重新起算；各題型內依題目編碼由小到大排列，未編碼題目排最後。章節名稱各行與功能勾選框下方保留間距。
- 題目資訊改為無框、無底色的黑色文字，例如「編碼：00252︱難易度：簡易題︱出處：課本︱頁數：P.25」。純數字頁碼自動加上 `P.`，已有頁碼前綴或其他來源文字保留原值。
- 題本的「解答、解析、出處、難易度」預設全部勾選；出處勾選項同時控制出處與頁數。取消勾選會立即更新預覽，題本列印與 Word 下載也依目前勾選內容輸出。題本不顯示試卷表頭，也不提供試卷儲存操作。
- 預覽卡片沿用其他選題頁面的標題樣式，列印與下載使用藍色按鈕。頂欄固定，頂欄下方的內容區獨立捲動；切換步驟時內容區回到頂端，預覽工具欄不另設滾軸。
- Word 保留章節粗體、分隔線與獨立資訊行，移除題本開頭多餘的空白段落及會顯示小方形編輯標記的段落分頁設定。題目使用實際文字寬度與定位點設定懸掛縮排，續行對齊正文；解析輸出為獨立段落。答案與答案標題保留紅色，解析保留藍色。
- 修正選擇紙張後無法下載的問題：文字寬度計算改在 Word 匯出函式內初始化，避免變數作用域錯誤，同時修復直接列印受影響的流程。
- 新增題本章節／編碼排序、題號重設、資訊格式，以及 Word 換段、顏色與下載流程測試。測試使用模擬 DOM 驗證匯出邏輯；實際 Microsoft Word 的字型、續行對齊、分頁及不同紙張／欄數仍需目視確認，瀏覽器與 Word 的分頁不保證完全一致。

## 2026-10-03 電腦選題與預覽調整

- 電腦選題改為五步流程：「出題範圍 → 題型與配分 → 自動選題 → 試卷設定 → 預覽試卷」，各頁沿用共用卡片、按鈕及線條圖示。
- 命題章節預設收合，可點選整列勾選，並支援 Shift + 滑鼠左鍵範圍選取；題目數為 0 的冊別與章節停用；展開科目時讀取冊別題數，章節及小節依該冊實際題目統計。標題顯示已選範圍的可選題數，僅最末層顯示個別題數。
- 題數不再限制為 99，依選定範圍的可用題庫驗證。填空題以「格」設定數量，系統選取完整題目湊足指定格數；配分與摘要顯示實際題數及總格數。
- 自動配分以接近 100 分及整數配分為優先，問答題與配合題的單題權重較高，是非題與選擇題配分盡量一致。「以整數配分」預設勾選，取消後以 0.5 分調整；可清除配分或重新自動配分。總分高於或低於 100 分時，進入自動選題前需確認。
- 難易度採較難題／簡易題兩類，偏難目標為 70%／30%，偏易為 30%／70%，適中為各 50%；題庫不足時依可用題目調整比例。選題後在各題型內混合難易度排序。
- 自動選題顯示完整題目與答案，選擇題的選項置於題幹與題尾之間；點選整列題型標題可收合題目，也可重選指定題型。頁面移除「重新排序」按鈕。
- 試卷設定以「試卷檢視」、「試卷表頭」上下兩張卡片呈現。檢視表格列出題型、題數、配分與小計，填空格數顯示在題數右側；底部以綠色圓角列靠左顯示「總分：XX 分」。題型列可拖曳排序，順序同步套用至預覽與儲存資料。
- 表頭卡片提供即時檢視、文字、班級／姓名／座號格數及欄位位置調整，格數設定排在考試範圍右側；此卡片不另設儲存變更、清除或取消按鈕，修改直接保留於目前草稿。
- 第五步直接在頁面內預覽試卷，使用整頁捲動；功能鍵位於「上一步」右側，不另設區隔符號。下載與新增的儲存按鈕採藍色，儲存時再輸入試卷名稱及說明，完成後留在預覽頁。
- 預覽新增「難易度」勾選項，以彩色圓角矩形顯示較難（橘色）與簡易（綠色）；是非與選擇題的標籤位於作答框前，其他題型位於題號前。解析與題目正文對齊縮排。
- 出題流程「上一步」改為灰藍底、白色文字；停用按鈕使用一般游標，避免處理中出現禁止圖示。

## 試卷匯出與排版功能（目前狀態）

- Word 匯出與網頁預覽共用試卷內容，表頭、題目、選項、題尾與解答以同一份試卷資料產生；表頭第一列在 Word 中標記為粗體。下載格式為真正的 OOXML `.docx`，由本地附帶的 docx.js 產生。
- Word 下載與直接列印前可選擇 A3（297×420 mm）、A4（210×297 mm）或 JIS B4（257×364 mm），以及單欄或雙欄題目版面；兩組選項都有示意圖，上次選擇會隨帳號在不同裝置同步。雙欄時表頭與解答保留整頁寬度。
- Word／直接列印共用頁邊距設定，預設上下左右各 10 mm，可在「進階設定 → 試卷版面設定 → 試卷邊距」調整為 5～50 mm；設定儲存在使用者帳號資料。
- 側邊欄「進階設定」整合「個人資料」、「常用科目」、「試卷版面設定」三個分頁；密碼更新卡片位於個人資料下方，管理員另有「帳號管理」入口。試卷版面設定依序提供「表頭欄位位置」、「字體與行距」、「試卷邊距」三張圖卡，各自儲存與重設。
- 試卷版面設定的初始值為系統預設字型、16 px、行距 1.3；行距可調整至 1.0～2.4，表頭固定為 1.6。帳號中的字體與行距設定只供新試卷使用；各試卷預覽中的調整儲存於該試卷，列印、Word 使用同一份試卷設定。變更預設值前會替尚未保存外觀的既有試卷保留舊值。「表頭欄位位置」可調整新試卷預設的列與列內順序；新試卷的表頭文字預設為空白，可在出題時或編輯試卷的「試卷表頭」個別填寫。新試卷建立時會保存當時的表頭；首次變更帳號設定前會為尚無表頭快照的既有試卷保存當前設定。預覽、列印、Word 讀取同一份試卷表頭。
- 常用科目、預設字體與行距、邊距、預設表頭，以及上次選用的紙張大小與欄數皆保存在使用者帳號的後台資料。登入時若帳號尚無對應值，系統會將舊版瀏覽器設定轉移一次，成功後移除舊值；每張試卷自己的外觀與表頭仍保存在該試卷資料中。
- 表頭文字以「學年度與學期」合併輸入，科目後可設定考試範圍；學校、學年度與學期、試別、科目與考試範圍的空欄位只顯示淡色範例，不會輸出。科目與考試範圍的範例分別為「例：全民國防教育」、「例：第1-3章」；空白欄位取得焦點時隱藏範例，失焦後恢復。班級、姓名、座號的格數預設為 8、8、0，可選 0–12 格；試卷上固定顯示欄名與指定數量的空格，不畫底線。試卷表頭第一行的欄位間距為半個全形字寬。
- 預覽與編輯試卷的「試卷表頭」提供班級、姓名、座號三個格數選單，以及各欄位文字與位置設定；變更只作用於目前的試卷或草稿，不覆寫帳號設定。年級已從表頭文字與欄位位置移除。
- 「欄位位置」以可拖曳標籤顯示上下兩行，能在同一行排序或跨行移動；儲存後預覽與輸出依新順序排列。既有第三行設定會接到第二行末尾。
- 表頭欄位位置的預設排列：第一行為學校、學年度與學期、科目、試別、考試範圍；第二行為班級、姓名、座號。已儲存的試卷及帳號自訂排列不會因預設值變更而改動。
- 是非題及選擇題以「（　　）題號」作為答題欄；長題目換行時，後續文字對齊第一行題目文字。預覽與列印使用表格定位，Word 匯出使用依前綴實際寬度設定的定位點與懸掛縮排，避免儲存格交界造成題號後空白與可見編輯記號。Word 解析另起段落，答案保留紅色、解析保留藍色。

- 預覽與編輯試卷的表頭設定另有醒目的「調整欄位位置」入口，預設收合；點開後可拖曳欄位於上下兩行排序。拖曳立即更新表頭，並與文字、格數共用「儲存變更」和「取消」。
- 預覽中的答題括號固定寬度，顯示答案時題號與題目不會位移；答案、解析、出處分別以紅色、藍色、綠色標示。
- 預覽中解析首行與題目正文左緣對齊，換行後對齊「【解析】」後的文字；字型選項以「明體」顯示 Noto Serif。
- 題目正文採靠左對齊；一般試卷預覽中的來源標記緊接題尾，不另加空格。題本的出處與頁數改顯示在題目上方資訊行。
- 選擇題的題目、選項、題尾在同一段自然接續，不強制在三者之間換行；題尾若只有「。」，不在句號前加入空格。

## 使用流程

### 第一次建立系統

1. 在 Firebase Authentication 啟用 Email/Password。
2. 建立 Firestore Database。
3. 如需題目圖片，啟用 Firebase Storage。
4. 確認 `index.html` 與 `js/firebase.js` 的 `firebaseConfig` 指向正確專案。
5. 發布 `firestore.rules`。
6. 第一個主要管理員由專案維護人員在 Firebase Console 建立 Authentication 帳號，並於 Firestore 的 `users/{uid}` 建立對應資料（`email`、`displayName`、`role: "admin"`）。網站不提供主要管理員初始化入口。

主要管理員可在「帳號管理」中建立管理員或教師帳號；一般管理員只能建立教師帳號。教師帳號必須填寫服務學校。

### 建立題庫

1. 在「課本管理」建立科目、冊別與章節。
2. 在「題目匯入」選擇科目與冊別，上傳 Word 入題檔。
3. 在「題目維護」查詢匯入結果；只有管理員可修改或刪除題目。

Word 入題檔的表格欄位為：難易、章數、節數、小節、題型、頁數／出處、來源、答數、簡答／答案、題目、選項1～5、結尾、詳答／解析。

「課本管理」依序選擇科目與冊別，再設定章節；畫面寬度不足時卡片會重新排列。「題目匯入」分為選擇科目、上傳 `.docx`、預覽解析結果、確認匯入四步，每個檔案上限 20 MB。「題目維護」需先選擇科目及冊次再搜尋，可用章節、題型與關鍵字縮小結果，並切換表格或卡片檢視。

題目文字以單一換行表示段內換行，以獨立段落標記表示換段。Word 表格中的 Shift+Enter 與 Enter 會按此規則匯入；題目編輯視窗也分別使用 Shift+Enter 與 Enter 輸入，換段只增加段距，不插入整個空白行。先前以兩個換行保存的段落會按換段顯示；舊題目原有的單一換行維持段內換行，已合併的斷行無法自動還原。

### 電腦選題

1. **出題範圍**：選科目、冊別與章節，可使用 Shift 範圍勾選。
2. **題型與配分**：設定各題型題數（填空題為格數）、每題／每格分數及難易度比例；點選「題型與題數」卡片右上角的「章節題目比重」開啟對話視窗，可將各節設為較少、一般或較多，預設一般。
3. **自動選題**：檢視完整題目與答案，收合題型或重選題目。
4. **試卷設定**：核對題數與總分、拖曳題型順序，設定試卷表頭。
5. **預覽試卷**：確認版面，切換解答、解析、出處與難易度顯示，列印、下載 Word 或儲存試卷。點選儲存後填寫名稱與選填說明。

一般試卷預覽左側提供獨立的「命題範圍」卡片，章節目錄預設全部展開並可收合，依章、節、小節顯示本卷題數。點選章節會以淡色底標示對應試題，再次點選可取消；切換解答、解析或字型時保留標示。標示僅用於預覽，不會輸出至列印或 Word。未記錄範圍的舊試卷依題目章節資料建立目錄，窄螢幕改為上方排列。

新建立的電腦選題試卷以 `scoreUnits.T4 = "blank"` 標記填空題按格計分；未帶此標記的舊試卷維持按題計分。自訂題型順序保存在 `typeOrder`。

章節比重以較多／一般／較少 = 3／2／1 作為分配參考，依課本目錄顯示已選範圍的最末層，名稱保留最後兩個層級。出題數不少於所選節數時，先確保每節至少一題，再分配剩餘題數；出題數少於節數時不受每節至少一題限制，仍依比重及難易度比例選題。填空以完整題目數判斷，保留指定格數；可涵蓋每節時優先涵蓋，否則僅在實際總題數少於節數時允許部分章節出題。題數足夠但某節缺少指定題型，或無法湊足題數／填空格數時，會要求調整設定。「重選題目」及個別「換題」採相同原則。實際比重會依可用題目調整，設定隨試卷儲存於 `sectionWeights`。

### 建立與輸出試卷

1. 使用電腦選題、人工選題或編碼選題建立試卷。
2. 儲存完成後仍停留在目前選題頁。
3. 前往「試卷管理」，直接瀏覽全部試卷清單。
4. 在試卷列表中進行預覽、直接列印、Word 匯出、編輯或刪除。列印或下載時可選擇 A3、A4 或 JIS B4 紙張與單欄／雙欄；預覽視窗也提供列印及Word 下載。

### 題本列印

1. 從側邊欄進入「題本列印」，選擇科目、冊次及章節；至少勾選一個有題目的章節。
2. 點選「預覽題本」，檢視各章節全部題型與題目。可切換解答、解析、出處及難易度，或展開「字體與行距」調整版面。
3. 點選「列印」或「下載」，選擇 A3、A4 或 JIS B4 與單欄／雙欄後輸出；資訊行、章節分隔線與勾選內容沿用預覽設定。

一般試卷 Word 下載使用瀏覽器的另存新檔功能，需以 Chrome／Edge 在 HTTPS 或 localhost 開啟。題本下載採瀏覽器一般檔案下載，不要求另存新檔 API；網站仍需透過 HTTP Server 開啟。

## 試卷管理介面

試卷管理直接顯示全部試卷清單，沿用首頁「最近試卷」的表格樣式，呈現試卷名稱、冊別、題數、建立時間與操作按鈕，支援試卷名稱搜尋及冊別篩選。

編輯試卷時可用「重新排序」隨機調整各題型內的題目順序；「題型排序」會開啟對話框，以拖曳調整題型先後。套用後的順序會儲存於試卷，並套用到預覽、列印及 DOCX。

### 列表篩選

- 可選擇「全部冊別」或指定冊別，選單依課本管理的科目與冊別順序排列，並與試卷名稱搜尋併用。
- 試卷預設依建立時間由新到舊排列；點選「試卷名稱」、「科目（冊別）」、「題數」或「建立時間」欄位標題可排序。
- 重複點選同一欄位標題會切換升冪與降冪；切換至其他欄位時預設使用降冪。
- 建立時間同時顯示日期及 24 小時制時間。

## Firestore 資料

| Collection／文件 | 主要用途 |
|---|---|
| `users/{uid}` | 管理員與教師資料、角色、服務學校、頭像，以及登入和試卷數量統計 |
| `questions/{questionId}` | 題目、答案、解析、題型與課本位置 |
| `exams/{examId}` | 試卷名稱、題目順序、配分與科目 |
| `textbooks/{subjectId}` | 科目資料 |
| `textbooks/{subjectId}/books/{bookId}` | 冊別資料 |
| `textbooks/{subjectId}/books/{bookId}/chapters/{chapterId}` | 章節資料 |
| `settings/questionStats` | 題庫統計快取 |
| `settings/questionCounter` | 題目流水號計數器 |

## 建議 Firestore 索引

| Collection | 欄位 | 用途 |
|---|---|---|
| `questions` | `subjectCode` ASC, `bookCode` ASC | 題目篩選 |
| `questions` | `subjectCode` ASC, `type` ASC | 科目與題型篩選 |
| `exams` | `createdBy` ASC, `createdAt` DESC | 使用者讀取自己的試卷 |

單欄位索引通常由 Firestore 自動建立。若查詢需要複合索引，Firebase 會在錯誤訊息中提供建立索引的連結。

## 部署注意事項

- 修改 `firestore.rules` 後必須重新發布，規則才會生效。
- 帳號管理的「目前保留試卷」會向 Firestore 查詢指定帳號的試卷數量；若新規則尚未發布或查詢配額不足，資訊視窗可能顯示查詢失敗或既有數值。
- Firebase 設定同時存在於 `index.html` 與 `js/firebase.js`，更換 Firebase 專案時兩處都要同步。
- 登入採用 `browserSessionPersistence`，關閉瀏覽器分頁後登入狀態會失效。
- 網站接受 `admin`（主要管理員）、`manager`（管理員）與 `teacher`（教師）角色。既有唯一的 `admin` 帳號自動視為主要管理員。
- 主要管理員可新增、編輯及刪除管理員與教師，但不能刪除自己或從網站改變自己的角色；管理員只能管理教師，不能管理主要管理員或其他管理員。網站不可建立或刪除主要管理員。
- 管理員新增工作人員時使用獨立 Firebase Auth instance，不會切換目前管理員的登入帳號。
- 前端只能讓使用者修改自己的 Firebase Authentication 密碼；若要由管理員重設或完整刪除其他人的 Auth 帳號，需要 Firebase Admin SDK 或 Cloud Functions。

### 靜態目錄版本更新

首次使用靜態目錄功能前，必須在「題目匯入」重新執行「匯出靜態題庫」，將壓縮檔中完整的 `data/testbank/` 發布到 GitHub。先上傳題目檔與 `catalog-*.json`，最後更新 `manifest.json`；檔案須與程式在同一部署版本中提供。既有發布資料沒有目錄，不能從題目推回完整課本結構，程式會明確提示重新匯出，不自動轉讀 Firestore。目錄檔名包含內容雜湊，重新載入頁面會取得最新索引；已開啟頁面維持當次版本，發布後請重新整理。

修改名稱、排序或章節後仍在課本管理儲存，再匯出與發布。調整科目／冊別代碼或章節編號時，須先同步題目歸屬；發布本身不會自動搬移題目。登入、來源設定及個人試卷仍使用 Firebase，因此 Firestore 讀取不會完全歸零。
